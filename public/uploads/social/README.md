# Social-share image uploads

These photos appear behind the existing text treatment when a page is shared
in texts, Slack, Facebook, LinkedIn, and similar services. Replace them **with
the same filenames** to update the photos without changing code:

- `home-share.jpg` — home page share card.
- `services-share.jpg` — services page share card.

Use a 1200×630 JPG, keep important subjects away from the edges, and keep each
file under 5 MB. The site's generated color overlay and text remain in place.

# Good Dog Days brand artwork

These SVGs are direct vector exports from the supplied `GOODDOGDAYS-BRANDING.ai` Illustrator master. Their path data has not been redrawn or approximated; only the exported artboard view boxes were cropped for efficient web display.

- `logo-primary.svg`: primary logo lockup and tagline
- `mark-primary.svg`: running dog and sun mark
- `same-good-energy.svg`: illustrated supporting brand artwork

Treat the Illustrator file as the source of truth for any future artwork changes.
